# Деплой на Render через MCP

Сервис выкладывается из Docker-образа (корневой `Dockerfile`), приложение внутри слушает порт из переменной окружения `PORT` - Render предоставляет её сам.

## Подключение MCP-сервера Render

1. Создайте API-ключ Render: [Account Settings - API Keys](https://dashboard.render.com/u/settings#api-keys).
2. Установите его в переменную окружения `RENDER_API_KEY` для процесса агента (пример для PowerShell: `setx RENDER_API_KEY "rlt_..."`, для bash: `export RENDER_API_KEY=rlt_...`).
3. Конфигурация агента уже в репозитории: `opencode.json` подключает remote MCP-сервер `https://mcp.render.com/mcp` и читает ключ через `{env:RENDER_API_KEY}` - сам ключ в файл не пишется.
4. Перезапустите агент, чтобы MCP-сервер подключился.

## Правила безопасности

- Ключ существует только в переменной окружения; в Git, чате и шаблоне его нет - в конфиге только подстановка `{env:RENDER_API_KEY}`.
- Утечка ключа - отзыв в Account Settings и выпуск нового.
- OAuth для OpenCode Render пока не поддерживает, поэтому используется только схема с ключом.

## Что делает агент после подключения

1. Создаёт Web Service из репозитория (Dockerfile, ветка main).
2. Ждёт деплой, проверяет `/api/health` и публичный URL.
3. Прогоняет сценарий гостя и владельца по публичной ссылке, включая отказ повторного бронирования.
4. Добавляет ссылку в README.
