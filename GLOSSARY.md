# Календарь звонков

Единственный контекст сервиса записи на звонок: владелец публикует типы встреч, гость без регистрации выбирает свободный слот и записывается на встречу.

## Language

**Владелец**:
Единственный держатель календаря, задан заранее, без авторизации. Управляет типами встреч и видит предстоящие встречи.
_Avoid_: Пользователь, аккаунт, админ

**Гость**:
Человек, который без регистрации записывается на встречу через публичную страницу.
_Avoid_: Клиент, посетитель, пользователь

**Тип встречи**:
Опубликованное владельцем предложение встречи: название, описание, длительность.
_Avoid_: Услуга, событие

**Встреча**:
Конкретная запланированная встреча - результат записи гостя на слот. Предстоящие встречи видит владелец в панели.
_Avoid_: Тип встречи, слот

**Публичная страница**:
Гостевая поверхность приложения: список типов встреч, точка входа в запись.
_Avoid_: Главная страница, лендинг

**Страница записи**:
Страница, на которой гость выбирает слот и оставляет данные - на неё ведёт карточка типа встречи.
_Avoid_: Страница бронирования

**Панель владельца**:
Поверхность инструментов владельца: управление типами встреч и список предстоящих встреч.
_Avoid_: Админка, личный кабинет, дашборд
